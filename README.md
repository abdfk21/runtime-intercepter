## 1. Project Title & Overview
**Project Title**: *Runtime Interceptor for Hallucination Cascades in Multi-Agent LLM Systems: An Adaptive, Architecture-Aware Approach to Error Containment*

This academic research repository implements an end-to-end, production-grade runtime interceptor that monitors agent handoff boundaries in multi-agent LLM systems to detect, contain, and repair hallucination cascades. It combines three orthogonal detection signals, adaptive per-model calibration, deterministic controlled fault injection, three LangGraph multi-agent architectures (Sequential, Hierarchical, Parallel-Consensus), statistical hypothesis testing, an interactive web dashboard, and reproducible benchmarking.

---

## 2. Research Problem & Objective
In multi-agent LLM pipelines, an ungrounded or hallucinated claim generated by an upstream agent (e.g., Researcher) is frequently accepted as a factual premise by downstream agents (Verifier, Critic, Synthesizer). These errors compound into an exponential **hallucination cascade**, leading to catastrophic misinformation in final outputs.

**Core Research Objective**:
Build a runtime middleware operating at agent handoff boundaries that detects suspected hallucinations, unsupported assertions, and premise contradictions in observable structured reasoning artifacts, mitigating cascades via localized repair loops and containment boundaries.

---

## 3. Core Contributions
1. **Zero Hidden Chain-of-Thought Dependency**: Replaces unobservable internal CoT with strictly observable structured reasoning artifacts (`answer`, `claims`, `confidence`, `evidence`, `assumptions`, `sources`).
2. **Tri-Signal Detection Architecture**:
   - **Signal 1: Schema Validator** (Pydantic structural & type validation)
   - **Signal 2: Reasoning & Claim Monitor** (Observable evidence similarity, numerical hallucination, and confidence inflation)
   - **Signal 3: NLI Cross-Agent Consistency Checker** (Premise-hypothesis entailment vs. contradiction)
3. **Adaptive Per-Model Calibration**: Independent empirical threshold and weight optimization per LLM to eliminate cross-model effectiveness gaps without data leakage.
4. **Architecture-Aware Containment**: Comprehensive evaluation across **Sequential**, **Hierarchical**, and **Parallel-Consensus** topologies.
5. **Research-Grade Evaluation**: Paired McNemar's test, Bootstrap 95% Confidence Intervals, Cohen's d effect sizes, and inter-annotator agreement (Cohen's & Fleiss' Kappa).

## 5. Installation & Quickstart

### 5.1 Local Environment Setup
```bash
# Clone repository
git clone https://github.com/your-org/runtime-interceptor.git
cd runtime-interceptor

# Create virtual environment
python -m venv venv
# Linux/macOS:
source venv/bin/activate
# Windows PowerShell:
.\venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 5.2 Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Default configuration uses the deterministic offline `MockProvider` and local SQLite database, requiring **zero paid API keys** and zero external network access.

## 6. Running the Project

### 6.1 Run the Controlled Demonstration
Demonstrates upstream hallucination propagation under `INTERCEPTOR_OFF` vs. active containment under `INTERCEPTOR_ON`:
```bash
python -m app.cli demo
```

### 6.2 Execute the Complete Autonomous Research Workflow
Executes the full automated pipeline end-to-end (generation $\rightarrow$ calibration $\rightarrow$ benchmarking $\rightarrow$ statistics $\rightarrow$ ablation $\rightarrow$ figures $\rightarrow$ tables $\rightarrow$ report):
```bash
python -m app.cli full-experiment
```

### 6.3 Launch the Interactive Web Dashboard
Starts the interactive dashboard and REST API on `http://localhost:8000`:
```bash
python -m app.cli dashboard
```

## 8. LLM Provider Configuration
The system features a transparent provider factory recording requested model, actual model, and fallback status:
- **Mock Provider (Default)**: Offline deterministic generation for reproduction and unit testing.
- **Google Gemini**: Set `GEMINI_API_KEY=your_key` in `.env`.
- **Groq Cloud**: Set `GROQ_API_KEY=your_key` in `.env`.
- **Ollama Local**: Run `ollama serve` and set `OLLAMA_BASE_URL=http://localhost:11434`.

## 10. Epistemic Humility & Limitations
The interceptor operates strictly as an anomaly and risk mitigation middleware. It calculates statistical risk scores ($R \in [0.0, 1.0]$) based on observable evidentiary alignment; it **never claims absolute ontological truth**. See `docs/limitations.md` for detailed discussion.
